AI Productivity Assistant

A FastAPI backend that pulls Gmail, Outlook, Google Calendar, Slack, and Telegram behind one API — with OpenAI-powered summarization and automatic task creation from whatever lands in your inbox.

Project Overview

AI Productivity Assistant is a FastAPI backend that treats "check my messages and calendar" as one API instead of five. It integrates Gmail and Outlook (via device-code OAuth) for reading and sending mail, Google Calendar for scheduling, and Telegram and Slack for messaging — all behind a single route surface, backed by a SQLAlchemy models layer for tasks and users.

An OpenAI-backed summarization service condenses long email threads or meeting notes on demand, and a task service turns action items pulled from Gmail or Outlook into tracked tasks with due dates and status, rather than leaving them buried in an inbox.

Auth for each provider is handled per-service — Outlook uses MSAL's device-code flow with a persisted token cache, Telegram runs through a Telethon client authenticated once and reused across requests — so adding a new provider means writing one service module, not touching the routing layer.

app/services/task_service.py 
def create_task(db: Session, user_id: str, title: str,
                description: str = None, due_date: datetime.datetime = None):
    task = Task(
        id=str(uuid.uuid4()),
        user_id=user_id,
        title=title,
        description=description,
        due_date=due_date,
        status="open",
        created_at=datetime.datetime.utcnow(),
    )
    db.add(task)
    db.commit()
    db.refresh(task)
    return task

Core Features

  • Unified Inbox API – Gmail and Outlook behind one schema, including device-code OAuth for Outlook.
  • Calendar Integration – List calendars and create events directly through Google Calendar.
  • Cross-Platform Messaging – Telegram (via Telethon) and Slack integrations alongside email.
  • Task Auto-Creation – Turns emails from Gmail/Outlook into tracked tasks with due dates.
  • AI Summarization – OpenAI-backed endpoint condenses long text or meeting notes on request.

Development Highlights

  • - Structured routes as a single router with per-provider service modules, so providers can be added without touching existing endpoints.
  • - Implemented Outlook's MSAL device-code auth flow with a persisted token cache across restarts.
  • - Built a SQLAlchemy-backed task model shared across every integration, instead of provider-specific task formats.
  • - Wrapped the OpenAI summarization call with error handling so a failed API call degrades gracefully instead of crashing the request.
