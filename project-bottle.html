Case Study / PROJ_04

Bottle Detection AI

A YOLOv8 model trained from scratch to detect plastic bottles in real time from webcam video — including a custom dataset pipeline that mixes a labeled bottle dataset with hard negatives mined from COCO.

Project Overview

Bottle Detection AI fine-tunes a YOLOv8 nano model to detect plastic bottles from live webcam footage. The interesting part isn't the model architecture — it's the dataset pipeline: a labeled Kaggle bottle dataset is combined with automatically downloaded negative samples from COCO 2017 so the model learns what a bottle isn't, not just what it is.

A dataset sanity-check pass (deep_check_and_fix.py, check_dataset.py) validates label files against their images before training even starts — catching mismatched classes, malformed bounding boxes, and orphaned label files that would otherwise silently corrupt a training run.

Training runs through a configurable CLI (train_bottle_yolo.py) with its own hyperparameter file, epoch/batch/image-size controls, and optional label visualization for debugging. The trained weights then drive a real-time OpenCV webcam loop that draws bounding boxes and a running FPS counter directly on the video feed.

Key Features

  • Real-Time Detection — Live webcam inference with bounding boxes and a rolling FPS counter.
  • Negative Mining — Automatically pulls non-bottle images from COCO 2017 so the model learns true negatives.
  • Dataset Validation — Pre-training sanity checks catch bad labels before they corrupt a run.
  • Configurable Training — CLI-driven training with custom hyperparameters, epochs, and image size.
  • Optional Recording — Annotated detection sessions can be saved directly to video.

Development Highlights

  • - Built a dataset pipeline mixing a labeled Kaggle bottle dataset with mined COCO negatives.
  • - Wrote pre-training dataset validation to catch label/image mismatches early.
  • - Tuned YOLOv8 hyperparameters via a dedicated config file rather than defaults.
  • - Built a real-time OpenCV inference loop with on-frame FPS and confidence overlays.
